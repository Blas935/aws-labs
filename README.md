# AWS Cloud Labs

Personal repository containing hands-on labs using **Amazon Web Services (AWS)**. Each lab includes a step-by-step PDF guide, screenshots of the completed work, and supporting scripts or files when applicable.

The goal is to learn by doing, document the process, and keep track of my progress in cloud computing.

> Labs are organized chronologically. They may later be reorganized by topic (networking, computing, storage, security, etc.).


Each lab is self-contained and includes:

- **README.md:** Objectives, services used, step-by-step summary, issues encountered, and resource cleanup.
- **instructions.pdf:** Detailed guide to reproduce the lab.
- **evidence/:** Numbered screenshots documenting the process.
- **files/:** Additional resources, scripts, or templates used during the lab.
